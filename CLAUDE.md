# Sketch: working rules

Read [CONTEXT.md](CONTEXT.md) before you run a test or touch a site. It says
which site takes a test run, and how to start the server the suite needs.

## Git

- Push as soon as the work lands: a commit on a branch, or a merge into `main`,
  reaches `origin` in the same reply. Standing authorisation, so push without
  asking. Confirm first only to force-push or rewrite shared history.
