High-fidelity frappe-ui prototypes, written by your own agent

Sketch has no editor and no agent panel. You connect the agent you already use, and you ask it to build a screen. The prototype renders in the browser with real frappe-ui components and real design tokens. Not a mock, not an image.

Sign in

Sketch signs you in with GitHub. The same button makes your account.

How it works

  1. 1

    You sign in and copy your token from Settings.

  2. 2

    You paste one block into your MCP client. Settings holds a ready-made block for eight clients, and each one already carries your token.

  3. 3

    You ask your agent to build a screen. It writes Vue files into a prototype: src/pages, src/components, src/App.vue, src/router.ts.

  4. 4

    The agent runs check. Sketch compiles the tree in a real browser, walks the routes, and answers with compile errors, console errors and one screenshot per route.

  5. 5

    The agent runs commit. Sketch records a version, with the prompt that produced it.

What you need

A GitHub account, and an agent that speaks MCP.

Clients that work today

Claude Code, Codex, OpenCode, Cursor, VS Code, Claude Desktop, Gemini CLI and Windsurf.

Claude Code takes one command. Your own token replaces the placeholder, and Settings prints the whole line for you. 

claude mcp add --transport http --scope user sketch \
  {{ mcp_url }} \
  --header "Authorization: Bearer <your-token>"

--scope user is not optional. Without it, Claude Code binds Sketch to one directory.

Limits, before you sign in

  • Sketch has no editor. Your agent writes every file, and you read the result in the browser.

  • A prototype has no backend. Data lives in plain refs inside the files, so the tree renders anywhere.

  • A prototype is private until you turn on its public link.

{# lucide-triangle-alert, the same glyph the Settings warning uses. Inline, because the `lucide-*` icon classes come from the frappe-ui Tailwind plugin and the website bundle does not carry them. #}

claude.ai connectors do not work yet

A claude.ai custom connector takes a URL only. It cannot send the Authorization header Sketch needs. Use one of the clients above.
